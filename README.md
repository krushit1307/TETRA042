# TETRA042 — Sasya AI / KrishiMitra

AgriTech platform for Indian farmers: AI crop disease diagnosis, multilingual advisory, and market tools.

## Repository structure

```
TETRA042/
├── frontend/     # Next.js web app (KrishiMitra UI)
└── backend/    # FastAPI + Gradio API (Sasya AI)
```

## Quick start (team)

### 1. Frontend

```bash
cd frontend
npm install
```

Create `frontend/.env.local`:

```
NEXT_PUBLIC_API_URL=https://neel2601-sasya-ai-backend.hf.space
```

```bash
npm run dev
```

### 2. Backend (optional — API is hosted on Hugging Face)

See [backend/README.md](backend/README.md).
